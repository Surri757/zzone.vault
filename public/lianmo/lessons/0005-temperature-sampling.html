DAY 03 · 第 1 题（基座模型方向）· 难度 ⭐+

大模型每生成一步在做什么？temperature 是什么？为什么同一个问题每次回答不一样？T=0 就完全确定了吗？

附带考点：自回归 · 解码三件套（T / top-k / top-p）· 贪心的复现性边界 ｜ 衔接 D1 token、D2「T 影响 Agent 决策稳定性」
真题源：基模岗通用连环炮（OpenAI 文档常引；字节/阿里变体「讲讲解码策略」「T 和 top_p 什么关系、怎么调」） 佐证：OpenAI API 文档（temperature 0~2 默认 1 · top_p 0~1 · 官方建议二选一调）· HuggingFace《How to generate》 改写声明：示例概率为教学玩具分布，机制保真于真实解码

S1🎭 开场：先盲猜一下

同一个问题问两次，模型给出了两个不同的答案。最可能的原因是？

提示：参数训练完就冻结；路由到不同模型是运营配置问题，不是机制。

S2🎲 每生成一步在做什么：逐 token 掷骰

三个结论（面试直接背）：

  • 每步只干一件事：读入已生成的全部内容 → 输出「下一个 token」在整个词表上的概率分布 → 按分布采样一个 → 拼回去，循环到掷出结束符。这叫自回归（autoregressive）。
  • 模型不写整句，只造"下一词的骰子"——你看到的流式输出，就是骰子一把一把掷出来的结果。
  • 衔接：D1 说它看不见 token 里的字母；今天补另一半——它也看不见"整句"，一次只有一个 token。D2 埋的「T 影响 Agent 决策稳定性」，根源就是这只骰子。

S3🌡️ temperature：骰子的偏心旋钮

  • 定义：采样前把每个词的原始得分 z 除以 T 再 softmax——p_i ∝ exp(z_i / T)。T<1 拉开差距（分布变尖、稳定），T>1 压平（发散），T=1 原始分布。取值 0~2，默认 1。
  • 为什么每次回答不一样：T>0 时是按分布采样而不是取最大——骰子每把不同。这不是"模型在思考"，是随机性来源本身。
  • top_p（nucleus）：0~1，先截掉长尾、只保留累计概率前 p 的候选再归一采样。官方口径：与 T 二选一调，不建议两个一起猛调（分布被两次扭曲，难解释难复现）。
✍️ 手推 30 秒（玩具分布 阳光.42 / 微风.28 / 雨.18 / 雪.12）：T=0.5 时等价于每个概率平方再归一→ .1764 / .0784 / .0324 / .0144 → 归一后 ≈ 58% / 26% / 11% / 5%。低 T 的本质：概率按 1/T 次幂向头部集中——分数高的被指数级放大。

S4🔬 动手实验室：温度采样模拟器

🎲 亲手掷 10 把骰子

固定玩具分布：阳光 .42 / 微风 .28 / 雨 .18 / 雪 .12。拖动滑块改 T，实线=当前缩放后分布，灰线=T=1 原始分布；点按钮按当前分布真实采样。

T =1.00
组件行为定义：① 滑块 0.1~2.0，实时按 p_i^(1/T) 重算并归一（与 exp(z/T) 等价）；② 「采样 10 次」严格按当前分布独立掷骰、累计计数，实测频率 vs 理论概率对照；③ T=0（贪心：永远阳光）不在滑块内——最低 0.1 已能看出趋势。
观察任务：T=0.1 连采 3 组，「雪」什么时候出现？再看 T=2.0——10 次里四种天气是不是都来了？

S5🔁 面试官追问链（点开前先自己答）

L1 · 「为什么不永远选概率最高的词（贪心）？」
💡 提示：一个永远说"标准答案"的人，聊天有意思吗？
再想想：如果每步都取最大，两个 token 循环互相强化会发生什么？

答案要点：贪心稳定但呆板——容易陷入重复循环、输出千篇一律；采样带来多样性与探索空间，也是 RLHF 训练目标希望的"分布别塌缩"。工程口径：代码/抽取/分类用低 T（求稳），写作/头脑风暴/给多样候选用高 T（求发散）——同一个模型，靠 T 切换性格。

L2 · 「top_p 和 temperature 什么区别？同时调会怎样？」
💡 提示：一个是"全体重新分蛋糕"，一个是"先踢人再分蛋糕"。
T 动的是每个候选的分数；top_p 动的是候选名单本身。

答案要点：① T 是全局缩放——所有候选按 1/T 次幂重新分配概率，长尾也被放大/压缩；② top_p 是截断——只保留累计概率前 p 的头部候选（nucleus），长尾直接出局，再在剩下的里归一采样（top_k 同理，只是按固定个数截）；③ 同时猛调 = 分布被两次扭曲，效果难解释、实验难复现——OpenAI 官方建议二选一调。这句"官方口径"说出来就是加分项。

L3 · 「T=0 就没有幻觉了吗？」（高频陷阱题）
💡 提示：把"答错"和"每次答得不一样"分成两件事想。
一个每次都坚定说错答案的人，和一个每次换着花样说错答案的人，谁"没有错"？

答案要点：① 不能。T=0 只消灭随机性，不消灭错误——幻觉是模型把没把握的内容生成得很有把握，根源在参数里的知识与训练分布，不是采样掷出来的；T=0 时它只会"每次稳定地胡成同一个答案"。② 反向补充：T=0 也不是百分百可复现——浮点运算顺序、批处理分组、硬件差异可能造成微小数值差，让个别 argmax 翻转。③ 一句话收尾：低 T 降低"随机"，不修复"知识性错误"——幻觉 ≠ 采样问题（明天 D4 幻觉解剖专拆）。

S8📇 今日知识卡（点击翻面，复盘日要刷）

「生成 = 逐 token 掷骰；
temperature 是骰子的偏心程度：
T 低偏心稳定，T 高公平发散。」
📇 点击卡片翻面 → 考点 / 易错 / 出处
考点：自回归（分布→采样→拼回）· T 缩放 logits（p∝exp(z/T)，0~2 默认1）· top_p 截断、二选一调 · T=0 贪心仍受数值差影响 · 幻觉≠采样问题
易错：把多样性当"模型在思考"；把调 T 当修复幻觉的旋钮；以为 T=0 百分百可复现；T 和 top_p 一起猛调
出处：OpenAI API 文档（temperature/top_p 口径）· HF《How to generate》· 各厂解码策略连环炮

S9🎤 60 秒面试答案（把今天的理解压成一段话）

如果你在面试里被问到这道题，可以这样答：
「大模型是自回归的：每一步基于已生成内容算出整个词表的概率分布，采样出一个 token 拼回去，循环到结束符。temperature 是采样前的缩放——logits 除以 T 再 softmax：T 小分布变尖、输出稳定，T 大分布变平、输出多样，取值 0 到 2、默认 1。所以同一个问题每次答案不同，不是模型在思考，是骰子不同。top_p 是截断累计概率头部再采样，官方建议和 T 二选一调。最后两个边界：T=0 是贪心，消灭随机但不等于百分百可复现，浮点顺序和批间分组都可能让 argmax 翻转；更重要的是 T=0 不解决幻觉——幻觉是知识性错误，不是采样问题。」
