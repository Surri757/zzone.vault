CARD #1 · 基模 · Day 01
「模型的世界由 token 组成，
它看不见 token 里的字母。」
📇 点击翻面 → 考点 / 易错 / 出处
考点：token 定义 · BPE 直觉 · 中文 token 成本 · 按 token 计费 · 上下文窗口单位

易错：以为模型逐字符阅读；以为「提示仔细点」能修复；把 token 等同于「字」或「词」

出处：OpenAI Tokenizer 文档 · 2024 strawberry 热梗 · wdndev/llm_interview_note
CARD #2 · AGENT · Day 01
「Agent = 会自己决定
下一步的 LLM 循环。」
📇 点击翻面 → 考点 / 易错 / 出处
考点：四模块（大脑/规划/记忆/工具）· 与 Chatbot、Workflow 的区别 · ReAct 循环 · 停止条件与护栏

易错：把「带联网按钮的 ChatGPT」就叫 Agent；把 Workflow 当 Agent（判据：流程谁写死）

出处：Lilian Weng 2023 · Anthropic《Building Effective Agents》· ReAct arXiv:2210.03629
CARD #3 · 基模 · Day 02
「上下文窗口 = 一次性工作记忆：
装 token、挤输入输出、
擦掉就没了。」
📇 点击翻面 → 考点 / 易错 / 出处
考点：定义（输入+输出共用）· 128k ≈ 6~10 万汉字 · ≠参数量 · Lost in the Middle（U 形）· 超窗三策略 · 长上下文 vs RAG 互补

易错：当永久记忆（跨对话靠产品层）；当参数量；以为窗口越大越好（成本/延迟/稀释）

出处：各厂通用题 · 阿里「200 万 token 了 RAG 还有何意义」· arXiv:2307.03172
CARD #4 · AGENT · Day 02
「模型点菜（输出调用 JSON），
你的厨房做菜（执行），
端回来它再尝一口说话。」
📇 点击翻面 → 考点 / 易错 / 出处
考点：五步闭环 · 意图/执行分离（模型从不执行）· schema 三件套 · 参数幻觉三防（枚举/必填/二次校验）· 错误回喂自纠 · FC 靠 SFT 轨迹数据训出

易错：以为模型自己执行了函数；description 随便写；失败就盲目重试不回喂

出处：OpenAI FC Guide（2023-06）· 美团「FC 三连炮」· 小林笔记 16 题 · Anthropic Tool Use
